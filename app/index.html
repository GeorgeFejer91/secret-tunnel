        About Secret Tunnel

        What this app does

        It lets ChatGPT read — and optionally edit — the files in one folder you choose on this computer. It does that by running a small file server on your machine and giving it a public web address that ChatGPT can call.

        Nothing is uploaded in advance. Files are read from your disk at the moment ChatGPT asks for them.

        What an MCP server is

        MCP, the Model Context Protocol, is a standard way for an AI assistant to call tools that someone else has written. The assistant does not get a folder; it gets a list of operations such as "list files", "read this file", "search for this text", and it calls them like functions and reads the replies.

        The MCP server here is gpt-repo-mcp, a Node program bundled inside this app. It offers those tools and refuses anything outside the folder you picked. In Read mode the tools that modify files are not offered at all.

        Why a tunnel is needed

        The file server listens on 127.0.0.1, the loopback address. That is not a personal address — it is the same number on every computer in the world, and on each one it means "this machine, talking to itself". Nothing outside your computer can reach it, by design. The port after it (8790 unless you change it) just picks which program on this machine answers.

        ChatGPT does not run on your computer; it runs in OpenAI's datacentre. It cannot dial your laptop — your router and firewall exist precisely to stop that.

        A tunnel solves that. This app uses zrok: it opens an outbound connection from your machine to zrok's servers and asks for a public HTTPS address. Requests arriving at that address are carried back down the connection you opened and handed to your local file server. You never have to open a port or change your router, because the connection was made from the inside out.

        What actually happens when ChatGPT reads a file

        1. ChatGPT sends an MCP tool call to your public address.
        2. zrok forwards it down the tunnel to the loopback port on this machine.
        3. The local server checks the request is inside your chosen folder, reads the file from disk, and replies.
        4. The reply travels back the same way. The app stays a courier; the files stay on your disk.

        What this means for your privacy

        • Only the folder you selected is reachable. Nothing above or outside it is offered.
        • The address contains a long secret token. Anyone who has the full address can read that folder, so treat it like a password.
        • In Read+write mode they could also change files in it. Use Read unless you need edits.
        • Close this window and the tunnel closes with it. The address stops working until you reopen the app.
        • The refresh button next to the address issues a brand-new one, which immediately invalidates the old.

        Why the address stays the same

        The name in your address is reserved on your zrok account, so it survives restarts and folder changes. That is why you only add the plugin to ChatGPT once, and can keep pointing the app at different projects afterwards.

        Setup instructions

        1. Enable zrok (one time)

        1. Open and create a free account.
        2. In the zrok console, copy your enable token.
        3. Paste it into the zrok token box in this window and press Enable.

        The token is used once to register this machine. It is not your MCP address.

        2. Choose the folder to share

        1. Press Select access folder and pick a project folder.
        2. Never pick a drive root, your home folder, or a system folder.
        3. Pick Read, or Read+write if ChatGPT should be able to change files.

        3. Wait for green

        ChatGPT can reach it must say Connected. That means a real MCP handshake succeeded through the public address. If it is red, the reason is shown underneath it.

        4. Add it to ChatGPT

        1. Press Copy next to the MCP Address above.
        2. In ChatGPT, open Plugins in the left sidebar, then New Plugin.
        3. Name: anything, for example Secret Tunnel.
        4. Connection: leave it on Server URL and paste the copied address.
        5. Authentication: choose No Auth. The address already contains a secret token.
        6. Tick I understand and want to continue, then press Create.

        Day to day

        • Keep this window open while ChatGPT is using the folder.
        • You can switch folders at any time — the MCP address stays the same, so you do not need to add the plugin again.
        • Treat the address like a password: anyone who has it can read the shared folder.
